# 🎛️ Balance Data-Driven (`src/config/`)

Todos los parámetros de diseño del juego (stats, tiempos de animación, paletas de skins, niveles de dificultad de IA, dimensiones de tablero/arena) viven aquí en archivos tipados contra `src/contracts/config.ts`. Prohibido hardcodear números mágicos dentro de `src/sim/` o `src/render/`.
